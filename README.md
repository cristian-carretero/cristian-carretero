## Featured Projects

### ParaSol — Data Architecture & Predictive Modeling
End-to-end pipeline for stability analysis of perovskite solar cells.
- **Data engineering:** modular 9-stage architecture processing 28M telemetry points into optimized Parquet, with disk-to-disk streaming and empirical validation of every threshold.
- **Predictive modeling:** Dual Digital Twin for early anomaly detection, hybrid kinematic engine for RUL forecasting (MAE 4.8 days), and multivariate autoregressive engine for physical parameter trajectories.
- **Deployment & XAI:** public Streamlit dashboard with integrated explainability (SHAP, surrogate trees).
- [View repository](https://github.com/cristian-carretero/perovskite-degradation-ml)

### Bachelor's Thesis — Explainable Machine Learning for Outdoor Perovskite Solar Cell Degradation
Research project focused on predictive modeling for physical systems reliability. Engineered ML pipelines to analyze time-series telemetry and degradation datasets of perovskite solar cells, applying XGBoost and Explainable AI (SHAP) to extract feature importance and interpret model predictions.
